Production-Grade Engineering

Vendor-neutral, modular architecture designed to scale from Oracle Always Free to dedicated multi-region clusters.

FRONTEND

Flutter (iOS, Android, Web)

Cross-platform client with Riverpod state management, Drift SQLite offline queue, and pure Dart ELM327 parser package.

BACKEND

Spring Boot Modular Monolith

Spring Boot 3.3 (Java 21 LTS), Spring Data JPA, Flyway migrations, and Spring Security OAuth2 resource server.

IDENTITY

Keycloak OIDC + PKCE

Configuration-as-code authentication with OAuth2 Authorization Code flow and PKCE for secure mobile app auth.

DATABASE

PostgreSQL 16 (+TimescaleDB)

Time-series partitioned telemetry readings with 90-day retention policies and nightly backups to object storage.

INFRASTRUCTURE

OpenTofu / Terraform

Cloud-agnostic IaC with network, compute, database, storage, Cloudflare WAF, and Stripe product modules.

EMULATION

Python ELM327 Simulator

Standalone TCP car simulator on port 35000 with live engine physics for developing without a vehicle.

Run It Locally in 2 Minutes

No vehicle or OBD hardware required. Start the built-in simulator and launch the app.

1. Start the vehicle simulator & telemetry streamer:

./run-local.sh

2. Launch the Flutter client in Chrome:

cd apps/mobile
flutter run -d chrome

3. Or launch all services in Docker (Postgres, Keycloak, API, Caddy):

make dev
